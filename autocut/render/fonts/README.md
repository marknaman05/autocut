# Bundled caption fonts

Shipped so the caption styles look the same on every machine. All are under
the SIL Open Font License (the `OFL-*.txt` beside each family): Anton and
Bebas Neue from Google Fonts, Montserrat from its upstream repository.

`CaptionConfig.font` names a file here by its stem (`Anton-Regular`); anything
not found here falls through to the system font directories.
